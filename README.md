# Sinema Daveti - GitHub Pages

Bu surum GitHub Pages uzerinden tamamen ucretsiz yayinlanabilir. Alan adi gerekmez.

## Yayinlama

1. GitHub'da yeni bir public repository ac. Ornek ad: `sinema-daveti`.
2. Bu klasordeki dosyalari repository'nin kok dizinine yukle.
3. Repository'de Settings > Pages bolumune gir.
4. Source olarak `Deploy from a branch`, branch olarak `main`, folder olarak `/root` sec.
5. GitHub sana su tarzda bir link verir:

`https://kullanici-adin.github.io/sinema-daveti/`
